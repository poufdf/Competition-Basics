## 一.题目解析
&emsp;&emsp;这道题意思很明确，就是对一个子矩阵的值同时加上k,执行q次后输出结果。
## 二.算法讲解
1.暴力解法
&emsp;&emsp;首先粗略想想暴力解法，时间复杂度为O(n * m * q),来到了 $10^{11}$级别，必超时，所以不考虑。
2.二维差分
&emsp;&emsp;我们之前做过一维差分的问题，它解决的是在一个区间内同时加减一个值的问题，这道题很类似，那我们就可以借助一维差分的思想解决这道题。
&emsp;&emsp;这道题概括起来就是在一个子矩阵上同时加减一个值，我们同样分为原数组和差分数组。请记住这一个核心原则：对差分数组作前缀和可以得到原数组。结合我画的图理解，在dif[x1][y1]加上k,那么以(x1,y1)为左上角，(n,m)为右下角的子矩阵都会加k。因为从(x1,y1)位置开始，对后面位置作二维前缀和运算时都会因为(x1,y1)多加了一个k而自己位置也要多加一个k。换个角度理解，(x1,y1)位置先不加k,正常对(x1+1,y1+1)位置作前缀和，因为(x1,y1)多加了一个k,所以(x1+1,y1+1)位置也要多加一个k。有了这个性质之后，实现子矩阵整体+k就很容易了，具体看图理解。

## 三.完整代码
```cpp {.line-numbers}
#include<iostream>

using namespace std;
const int N = 1000 + 10;
long long a[N][N];
long long dif[N][N];

//二维差分数组的核心处理逻辑
void update(int x1, int y1, int x2, int y2, int k)
{
    dif[x1][y1] += k;
    dif[x1][y2 + 1] -= k;
    dif[x2 + 1][y1] -= k;
    dif[x2 + 1][y2 + 1] += k;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n, m, q;
    cin >> n >> m >> q;
    //为什么这里不直接插入到原数组，而要用差分数组的性质插入
    //因为要用差分数组的前缀和得到原数组,原数组相当于在以(i,j)为左上角，(i,j)为右下角的区域+k
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
        {
            int x;
            cin >> x;
            update(i, j, i, j, x);//重复逻辑封装成一个函数
            //dif[i][j] += x;
            //dif[i][j + 1] -= x;
            //dif[i + 1][j] -= x;
            //dif[i + 1][j + 1] += x;
        }
    }
    while (q--)
    {
        int x1, y1, x2, y2, k;
        cin >> x1 >> y1 >> x2 >> y2 >> k;
        update(x1, y1, x2, y2, k);
        //dif[x1][y1] += k;
        //dif[x1][y2 + 1] -= k;
        //dif[x2 + 1][y1] -= k;
        //dif[x2 + 1][y2 + 1] += k;
    }
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
        {
            a[i][j] = a[i - 1][j] + a[i][j - 1] - a[i - 1][j - 1] + dif[i][j];
        }
    }
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
        {
            cout << a[i][j] << ' ';
        }
        cout << '\n';
    }

    return 0;
}
```
